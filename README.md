# BEC Handball · pronos et stats (SF1)

Site publié sur https://bechandballstats.com : pronostics, calendrier, classement, stats rigolotes et fiches joueuses de l'équipe SF1 du BEC Handball (Bordeaux Étudiants Club, Excellence Régionale Féminine poule A), à partir des données publiques de ffhandball.fr.

Même code que https://medochandballstats.com, aux couleurs du BEC. `index.html` est régénéré et republié automatiquement chaque semaine.
